Jorik CLI 0.5.0 brings the Desk player, safer sign-in and verified updates.

### Player

- New Desk layout with album artwork, track details, metadata columns and responsive queue views.
- Browse real queue pages with `[` / `]`; press Enter for track details and `a` or `/` to add music.
- Retain music queries after failed or uncertain submissions; reject stale responses and show confirmed playback state.
- Improve Unicode editing, lyrics navigation, connection recovery and terminal cleanup. Support `NO_COLOR` and artwork fallbacks.

### Sign-in and upgrading

- Store credentials in Windows Credential Manager, macOS Keychain or Linux Secret Service, scoped to the API server.
- Use one-time login codes with S256 PKCE and a validated, cancellable loopback callback.
- The public backend supports the new login protocol. Custom servers must deploy the paired backend protocol before using 0.5 login.
- Old plaintext credentials are never migrated automatically. Sign in again, or explicitly migrate with `jorik auth migrate --confirm-server https://jorik.gleckson.com`. Use your own server URL for custom deployments.
- Linux requires an available, unlocked Secret Service provider for saved credentials. Environment tokens remain available for headless use.

### Downloads and updates

Linux x86_64 and Windows x64 packages include SHA-256 checksums and GitHub/Sigstore build provenance. The updater and Linux bootstrap verify the exact release tag and trusted build workflow before installation. Verification requires a current, authenticated GitHub CLI.

From a trusted local checkout on Linux:

```sh
bash installer/install.sh --tag v0.5.0 --dest "$HOME/.local/bin/jorik"
```
